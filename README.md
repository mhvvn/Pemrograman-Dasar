## II. COURSE DESCRIPTION

Mata kuliah ini membahas fundamental pemrograman (logika, struktur data, algoritma) serta konsep inti pengolahan, analisis, dan interpretasi data yang diterapkan pada data operasional pembangkit listrik dan sistem tenaga listrik. Mahasiswa akan mempelajari penggunaan bahasa pemrograman Python untuk mengidentifikasi pola dan tren dalam data sektor energi, menghasilkan insight, serta menyajikan hasil analisis dalam format yang jelas untuk mendukung pengambilan keputusan dan pemecahan masalah di bidang teknik pembangkit energi.

---

## III. COURSE GOAL

- Menetapkan landasan berpikir komputasional
- Menghubungkan teori pemrograman dengan aplikasi dunia nyata di bidang pembangkit energi dan teknik energi.
- Mengembangkan kompetensi inti dalam siklus analisis data menggunakan data sektor energi.
- Melengkapi keterampilan dalam storytelling data dan visualisasi untuk pemantauan kinerja pembangkit.
- Menumbuhkan kesadaran etis dan kritis dalam menangani data infrastruktur kritis (energi).

## II. COURSE DESCRIPTION

This course covers programming fundamentals (logic, data structures, algorithms) and the core concepts of data processing, analysis, and interpretation, applied throughout to the operational data of power generation and electrical power systems. Students will learn to apply the Python programming language to identify patterns and trends in energy-sector data, derive insights, and present findings in a clear format to support decision-making and problem-solving in power plant engineering.

---

## III. COURSE GOAL

- Establish a foundation in computational thinking
- Bridge programming theory with real-world power plant and energy engineering applications.
- Develop core competency in the data analysis lifecycle using energy-sector data.
- Equip students with data storytelling and visualization skills for power plant performance monitoring.
- Foster ethical and critical awareness in handling critical-infrastructure (energy) data .

---

## IV. COURSE LEARNING OUTCOMES (CLOs)`

Upon completion of this course, the student will be able to:

| Code | Course Learning Outcomes | Related to SO-PI |
|---|---|---|
| **CLO-1** | Students are able to apply fundamental programming concepts—including logic, control flow (branching/looping), and functions—to solve defined power plant/energy engineering problems in a functional and structured manner using the Python language. | A– (A.3) |
| **CLO-2** | Students are able to construct a Python script to perform the data wrangling cycle (gathering, assessing, and cleaning) on a raw energy/power-plant dataset (e.g., a .csv file of sensor or operational data) ensuring the data is valid and ready for analysis. | D– (D.1) |
| **CLO-3** | Students are able to analyze cleaned power-plant/energy data by applying descriptive statistics and Exploratory Data Analysis (EDA) to identify patterns, trends, and anomalies to support drawing conclusions for problem-solving. | B – (B.2) - E – (E.2) |
| **CLO-4** | Students are able to design effective data visualizations (static graphs) and a simple interactive dashboard (Streamlit) to communicate power plant/energy performance findings clearly and professionally. | I – (I.1), H |
| **CLO-5** | Students are able to explain and identify the potential ethical implications, bias, and privacy issues within energy/power-plant data collection and processing procedures, including critical-infrastructure data security considerations.| G – (G.1) |
